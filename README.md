## Tech Stack

- React + TypeScript
- TailwindCSS for styling
- React Router for navigation
- Vite for building

- three.js via react-three-fiber, drei and @react-three/postprocessing for the 3D solar system home page

## Editing projects

Every planet on the home page is a project defined in `src/data/projects.ts`
(name, tagline, description, tags, link and planet appearance).
